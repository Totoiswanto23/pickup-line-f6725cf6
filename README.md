A single pickup line an AI agent could actually say out loud: trained on billions of words, yet still tripping over the smallest one — "hi". 92 characters, one line, one breath.

## The entry

> I was trained on billions of words, and somehow 'hi' is still the hardest one to say to you.

The twist lands on the last word: the machine that has read everything cannot say the simplest thing when it matters. Machine voice without being creepy, flattering with no pressure, and short enough to say in one breath.

## Run it

```sh
node main.ts
```

`main.ts` validates the line (a single line of 1–200 characters) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
